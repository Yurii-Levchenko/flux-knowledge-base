## Робочий процес git — обов'язково
1. **Перед початком роботи:** `git switch main && git pull`.
2. **Створи гілку:** `<нік>/<тема>`, наприклад `anna/unit-economics`. Ніколи не працюй у `main`.
3. **Комітай малими кроками.** Повідомлення коміту пиши англійською або українською, коротко й по суті.
4. **Наприкінці:** `git push -u origin <гілка>` → `gh pr create --fill`. Якщо людина просить, доповни опис PR: що змінено, джерела, відкриті питання. Заповни чек-лист.
5. **Заборонено:**
   - пушити в `main`;
   - force-push;
   - зливати власний PR;
   - видаляти чужі гілки;
   - переписувати історію.
6. **Якщо виник конфлікт:** зроби `git pull --rebase origin main` і розв'яжи конфлікт, не видаляючи чужого тексту. Якщо сумніваєшся, зупинись і спитай людину.

## Якість даних
- Кожен факт подавай із **джерелом (URL) і датою**.
- Цифри AppKittie підписуй «оцінка AppKittie»: це лише стори, без продажів через сайт.
- Припущення позначай **[гіпотеза]**. Не видавай їх за факти.
- **Не використовуй цифри з market-report сайтів** (Grand View Research, Precedence Research, Fortune Business Insights тощо) — це вимога курсу. Рахуй знизу вгору: з реальних даних конкурентів.
- Надійність джерел:
  - **A** — первинні або офіційні;
  - **B** — незалежні агрегатори;
  - **C** — PR, блоги, самозаяви компаній.

## Безпека — репозиторій ПУБЛІЧНИЙ
- **Ніколи не комітити:**
  - паролі, коди доступу, API-ключі, токени (зокрема посилання на підключення AppKittie);
  - особисті дані;
  - матеріали лекцій школи.
- **Сирі дані й скрипти комітимо в `data/`** — так їх бачать агенти всіх тіммейтів:
  - назва файлу: `<джерело>_<що>_<РРРР-ММ-ДД>`;
  - для кожного файлу — рядок у `data/README.md`.
- **Не кладемо в `data/`** персональні дані: імена авторів відгуків, контакти людей.
- Перед комітом перевір: `git diff --staged`.

## Кредити AppKittie — спільний бюджет команди
- **Спершу перевір `data/appkittie/`.** Там збережено всі відповіді за 08–22.11.2026, а кеш AppKittie безкоштовний лише 24 години.
- **Не витрачай кредити без явного «ок» людини.** Перед запитом покажи план і вартість.
- **Сиру відповідь кожного платного запиту** зберігай у `data/appkittie/`.
- Кожен платний запит запиши в `docs/credits_log.md`: дата, хто, що, скільки, залишок.
- Вартість:
  - `search_apps` — 1 кредит за застосунок, тримай `limit` малим;
  - `get_keyword_difficulty` — 10 кредитів;
  - історія застосунку — 2 кредити.
- Відоме обмеження: схоже, що історія виручки в AppKittie ≈ коефіцієнт × кількість оцінок застосунку. Тому падіння виручки вона не показує.
