# Flux — база знань команди (Genesis Warsaw IT School 5.0, Final Project)

Спільна база знань команди **Flux**. Тут зберігаються:
- дослідження ринку;
- аналіз конкурентів;
- рішення щодо продукту;
- юніт-економіка;
- матеріали для пітчу.

**Ніша:** Collectibles — AI-сканер, ціна та портфель колекції. Старт з Pokémon TCG, далі монети, спортивні картки, каміння.

## Правила

1. **Кожен факт — з джерелом і датою.** Цифри AppKittie підписуємо «оцінка AppKittie».
2. **Факти окремо від припущень.** Припущення позначаємо **[гіпотеза]**.
3. **Ніяких секретів:** паролів, кодів доступу AppKittie, API-ключів, особистих даних. Репозиторій **публічний** — його бачить будь-хто.
4. **Сирі дані сюди не кладемо** (вивантаження AppKittie, масиви відгуків). Вони зберігаються локально в автора. У документах — лише висновки й агреговані цифри.
5. **Матеріали курсу** (лекції, нотатки Q&A) — у закритому каналі школи, не тут.
6. **Зміни — через Pull Request.** Пряма зміна гілки `main` закрита; кожну зміну переглядає ще хтось із команди. Як це зробити — у [CONTRIBUTING.md](CONTRIBUTING.md).
